# Repository Guidelines

## Project Structure & Module Organization

- `UnrealGit.uplugin`: Plugin descriptor (module name/type/loading phase).
- `Source/UnrealGit/`: Primary C++ module.
  - `Public/`: Exported headers.
  - `Private/`: Implementation files.
  - `UnrealGit.Build.cs`: Unreal Build Tool (UBT) module rules/dependencies.
- `Resources/`: Plugin resources (e.g., icons). Note: `*.png` uses Git LFS via `.gitattributes`.
- `Content/`: Optional Unreal assets (this plugin currently allows content).
- `Binaries/`, `Intermediate/`: Generated by Unreal; do not commit (already ignored in `.gitignore`).

## Build, Test, and Development Commands

This repository is an Unreal Engine plugin. The most reliable workflow is to install the plugin into a host Unreal project and build from the Editor/IDE.

- Build in-editor: enable the plugin, then compile the project (or use your IDE build for `UnrealEditor`).
- Package a distributable plugin (from an Unreal Engine checkout):
  - `"$UE_ROOT/Engine/Build/BatchFiles/RunUAT.sh" BuildPlugin -Plugin="$PWD/UnrealGit.uplugin" -Package="$PWD/Dist" -TargetPlatforms=Win64+Linux`
- Clean rebuild: delete `Binaries/` and `Intermediate/` and rebuild.

## Coding Style & Naming Conventions

- Follow Unreal Engine C++ conventions (prefixes like `F`, `U`, `A`, `E`; `b` for booleans; `PascalCase` types/functions).
- Keep headers in `Public/` minimal and stable; prefer forward declarations when possible.
- Match existing formatting (tabs/brace style) and Unreal reflection macros (`UCLASS`, `UFUNCTION`, etc.).

## Testing Guidelines

- No automated tests are currently present. Validate changes by compiling the plugin and running the host project.
- If adding tests, prefer Unreal’s Automation Framework and keep them isolated from runtime code.

## Commit & Pull Request Guidelines

- Existing history is minimal (e.g., “Initial commit”). Use concise, imperative subjects going forward.
- Suggested pattern: `UnrealGit: <change summary>` (add context in the body when needed).
- PRs should include: what changed, how to verify (steps/commands), Unreal Engine version(s) tested, and screenshots for any UI/editor-visible changes.
